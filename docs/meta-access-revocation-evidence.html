Initiation of revocation (example UI control)

When access is no longer required, no longer used, or a person leaves the organization, an authorized operator opens the team/members page and initiates revocation:

Remove member Revoke access

SystemWhere revocation is initiatedTrigger
Vercel Team → Members → Remove Role change / unused / departure
Supabase Organization → Team → Remove member Role change / unused / departure
GitHub Org/Repo → People/Collaborators → Remove Role change / unused / departure
Meta Developer App Roles → Remove role Role change / unused / departure
