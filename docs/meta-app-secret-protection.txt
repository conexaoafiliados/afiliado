PROTECTION OF META APP SECRET
=============================

Organization: Conexões Consultoria e Treinamentos Ltda — CNPJ 45.659.882/0001-50
Application: Conexões Creators
Question reference: appsecret-13.d.i
Effective date: 30 October 2026

1. PURPOSE
----------
This policy/procedure explains how we protect the Meta App Secret from unauthorized
use and unauthorized read access.

2. PROTECTION FROM UNAUTHORIZED READ ACCESS (HIGHLIGHTED)
---------------------------------------------------------
>>> The App Secret is protected from unauthorized read access as follows: <<<

- Stored only as the server environment variable META_APP_SECRET on the production
  host (Vercel) and in private local .env for development.
- Loaded only by the backend server process for OAuth / Meta API server-side calls.
- NEVER returned by a network call to a browser or mobile client.
- NEVER embedded in distributed frontend JavaScript or public repositories.
- Access to production secret configuration is limited to authorized operators of
  Conexões Consultoria e Treinamentos Ltda.

3. LOG FILES — CLEARTEXT PROHIBITION (HIGHLIGHTED)
--------------------------------------------------
>>> REQUIREMENT: The App Secret MUST NEVER be written to log files in cleartext
>>> (unencrypted) form. <<<

Operators and developers must:
- Not print, console.log, or persist the App Secret in application logs, error
  tracking, analytics, screenshots shared externally, or support tickets.
- Redact the secret if debugging configuration (never paste the full value).
- Treat accidental logging of the App Secret as a security incident: rotate the
  App Secret in the Meta App Dashboard and update environment variables immediately.

4. ATTESTATION
--------------
Conexões Consultoria e Treinamentos Ltda attests that the Meta App Secret for
Conexões Creators is protected as described above, including the prohibition on
cleartext logging.
